📊 Google Sheets Backend Setup

Step 1: sheets.google.com → Create a new blank spreadsheet (any name — tabs are created automatically, no manual setup needed)
Step 2: Extensions → Apps Script → delete the default code → paste in the full Code.gs file provided with this update
Step 3: ⚙️ Project Settings → Script Properties → Add 3 properties:
ADMIN_PASSWORD  → choose your own strong password (replaces the old "owner123") RAZORPAY_KEY_ID  → from Razorpay Dashboard → Settings → API Keys RAZORPAY_KEY_SECRET → from Razorpay Dashboard → Settings → API Keys (keep this one secret!)
Step 4: Deploy → New deployment → Web app → Execute as: Me → Who has access: Anyone → Deploy → copy the /exec URL
⚠️ Step 5 — the important one: open index.html in your GitHub repo and paste this same URL into DEFAULT_SHEET_URL near the top of the <script> tag, then commit. The box below only saves the URL for this one browser — useful for quickly testing the connection, but every other visitor still needs the URL to be inside the file itself.

⚡ Razorpay Auto-Checkout

Paste your Razorpay Key ID below (starts with rzp_) to test in this browser — then also paste it into DEFAULT_RAZORPAY_KEY in index.html so every visitor gets it. This Key ID is public and safe to store in the file. Your Key Secret only ever goes in Apps Script Script Properties above — never here, never in GitHub.
